# Rick & Morty Characters App

Aplicación hecha con Angular que muestra los personajes de Rick and Morty
usando la API pública https://rickandmortyapi.com/

## Tecnologías
Angular, TypeScript, HttpClient, RxJS y Signals.

## Cómo ejecutarlo
1. Clona el repositorio: `git clone URL-DE-TU-REPO`
2. Entra a la carpeta: `cd rick-morty-app`
3. Instala las dependencias: `npm install`
4. Arranca la app: `ng serve`
5. Abre http://localhost:4200
